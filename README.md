# 深鲸 Mobile · DeepWhale Mobile

**手机上的 DeepSeek Harness。** 不是"只能看"的遥控器：手机端和桌面端共用同一套会话、模型与权限。
局域网扫码即连，外出走自建中继；安卓与鸿蒙可以同时在线。

- 官网介绍：https://deepwhale.org.cn/mobile.html
- 使用指南：https://deepwhale.org.cn/mobile-guide.html
- 下载：https://deepwhale.org.cn/dl/mobile-apk

## 功能（1.1 完全体）

- **会话与聊天**：会话列表、全文搜索、历史消息、Markdown 渲染、图片查看；新建会话。
- **图片附件**：拍照 / 相册 / 文件三入口；图片压缩后上传；模型不支持读图时先拦下并提示，不白发。
- **模型与强度**：切换模型、调推理强度；模型名完整显示（长名省略）。
- **权限预设**：仅可查看 / 工作区内修改 / 完全权限 / 自动审查（EXP），与桌面端同源。
- **停止与排队**：运行中发送键变方块可随时停止；运行中再发进入"排队中"，支持插话 / 编辑 / 删除。
- **轨迹**：按轮查看思考与工具调用。
- **定时任务**：「任务」页查看全部定时任务与下次触发时间。
- **多端同时**：安卓 + 鸿蒙可同时在线；审批任意一台点一次即生效。
- **我的**：连接状态（局域网 / 公网中继）、外观、官网、版本更新说明。

## 使用（三步）

1. 桌面端打开「手机连接」→「开启手机访问」（显示二维码 + 6 位配对码）；
2. 手机打开深鲸 → 扫码，或填面板上的地址 + 配对码；
3. 进入会话列表即成功；之后重开 App 自动进入，不用再配对。

> 不需要公网 IP、不用自己配 nginx/frp：桌面端内置网关与自建中继隧道，局域网直连、外出走中继。

## 安全

- 配对码一次性、5 分钟有效；配对后换长期令牌，只对你这台电脑的手机网关有效；
- 中继只转发字节，不懂内容；全程 HTTPS / WSS；
- 会话、附件、模型 Key 全部留在你自己的电脑上，App 不收集数据。
